# 涉外诉讼案件工作区

> **本分支更新（2026-11-25）**：已同步以人工复核为主的脱敏工作台，包含紧凑双栏布局、补标关键词全文匹配和撤销功能。当前启动方式、功能范围与验证命令见 [脱敏工作台说明](DESENSITIZATION_WORKBENCH.md)。下文保留的是历史版整体产品说明，其中的 LLM/RAG 及自动归档描述不代表本分支默认行为。

> 前台收件箱 | 自动 OCR 归档 | 本地脱敏 | 智能问答 | 纯本地运行  
> 适用: 中伦律师事务所 · 涉外诉讼 · 产品质量纠纷

一套**全本地、数据不出机**的诉讼案件管理工具：文件丢进收件箱自动归位、
一键脱敏出稿、基于案件材料的本地 AI 问答。所有 AI 能力（OCR / NER / 向量检索 /
问答）都跑在本机（Ollama + PaddleOCR + ChromaDB），不向任何云端上传数据。

---

## 快速开始

```bash
# 1. 解压后运行（仅第一次）
bash setup.sh

# 2. 新建一个案件
bash bin/new_case.sh "2026-甲公司-产品责任纠纷"

# 3. 编辑 auto_filer/config.yaml，在 cases 下添加案件关键词

# 4. 启用自动归档（含智能命名）
bash bin/filer.sh start

# 5. 往 inbox 丢文件 → 自动归位
```

## 🛡 脱敏工具（本地离线）

把文件里的敏感信息替换成一致化名，出稿给外部时不泄露当事人身份；凭加密映射表可随时还原。**全程本地，原件与映射表都不出机。**

**识别类别**（可勾选脱敏范围）：

| 类型 | 覆盖 |
|:--|:--|
| 主体 | 人名、公司/机构名、地址 |
| 联系方式 | 电话、邮箱、微信号 |
| 证件/账户 | 身份证、统一社会信用代码、银行卡、证券账户、车牌、SSN、EIN |
| 其它 | 金额、案号 |

**核心能力**：

- **化名一致性**：同一实体在全文/跨文档始终用同一化名（如「纽约川普机械贸易有限公司」「川普公司」「川普」→ 都是〔甲公司〕）。
- **案件当事人自动打通**：从案件收件箱/已归档文件进入脱敏时，自动把该案当事人的**全称 + 别名 + 曾用名**设为已知主体、共用化名，证件号一并脱敏——NER 漏了也不会漏脱。
- **人工校订**：自动脱敏后可**划选补脱敏**、**删除误识别项**、给某化名**追加别名**。
- **加密映射表**：导出脱敏文的同时生成 `.vault`（**AES-256-GCM**，密钥 = 口令 + 本机机器码，换机器即解不开）。
- **还原回填**：凭 `.vault` 把化名替回真名。
- **输入格式**：docx / PDF / 图片（OCR）/ 粘贴文本；中英双语。
- **引擎**：本地 Ollama `qwen2.5:7b`（NER）+ 规则库，纯离线。

## 💬 智能问答（本地 RAG）

针对案件材料提问，得到**带来源引用**的回答，免去逐份翻阅。

- **检索**：案件文件切块后进本地向量库（`bge-m3` 1024 维向量 + **ChromaDB** 持久化），语义召回相关段落；可限定案件/文件范围。
- **生成**：本地 Ollama `qwen2.5:7b` 依据召回内容作答，**SSE 流式**输出，附出处。
- **本地**：向量库与模型都在本机，问答内容不出机。

> 依赖本机已装 [Ollama](https://ollama.com) 并拉取模型：`ollama pull qwen2.5:7b && ollama pull bge-m3`。

## 添加新案件

编辑 `auto_filer/config.yaml`：

```yaml
cases:
  - key: "NewCase"
    name: "2026-新客户-案由"
    keywords: ["新客户", "NewClient", "产品型号", "案号"]
```

然后运行 `bash bin/new_case.sh "2026-新客户-案由"` 创建文件夹。

## 智能文件命名

文件归档时自动从内容提取信息，拼成标准名称：

**格式**: `[文档日期]-[案件简称]-[(案号)]-[文书类型]-[版本号].[扩展名]`

| 原始文件名 | → 智能命名 | 提取来源 |
|:--|:--|:--|
| `新文档_1.docx` | `2025-03-15-甲方-(00001)-民事起诉状.docx` | 内容: 2025年3月15日 / X0000民初00001号 / 标题"民事起诉状" |
| `Document_v0.2.docx` | `2026-06-22-甲方-质证意见-v0.2.docx` | 内容: 标题"质证意见" / 原文件名: v0.2 |
| `乙方答辩状-终稿.docx` | `2026-06-22-乙方-民事答辩状.docx` | 内容标题比原名更精确 |
| `IMG_5921.jpg` | `2026-06-22-甲方-IMG.jpg` | OCR 模糊时降级保留关键词 |

**各字段提取优先级**:

| 字段 | 优先级1 | 优先级2 | 优先级3（兜底） |
|:--|:--|:--|:--|
| 日期 | 内容中 `2025年3月15日` | 内容中 `2025-03-15` | 当前日期 |
| 案号 | `(2025)X0000民初00001号` → `00001` | `00001号` | 不填 |
| 文书类型 | 内容标题（docx首个标题） | 规则 rename_pattern | 原文件名关键词 |
| 版本号 | 原文件名 `v0.2` | — | 不填 |
| 案件简称 | config.yaml case key | — | — |

**切换模式**（`auto_filer/config.yaml`）：

```yaml
naming:
  mode: "smart"       # smart=智能提取 | simple=日期+类型 | keep=保留原名
```

## 添加新归类规则

编辑 `auto_filer/config.yaml` 的 `rules` 段：

```yaml
rules:
  - keywords: ["新文书类型", "document type"]
    target: "04_诉讼文书/新目录/过程稿"
    rename_pattern: "新文书"
```

## 系统要求

- **Python**: 3.10+
- **系统工具**: `tesseract-ocr` (含中文包 chi_sim) + `poppler-utils`
- **Python 包**: watchdog, pyyaml, python-docx, openpyxl, pytesseract, Pillow；脱敏/问答另需 flask、chromadb、cryptography、paddleocr
- **本地 AI（脱敏 NER / 问答）**: [Ollama](https://ollama.com) + 模型 `qwen2.5:7b`（问答/NER）、`bge-m3`（向量检索）
  ```bash
  ollama pull qwen2.5:7b && ollama pull bge-m3
  ```
- **macOS**: 推荐配 launchd 开机自启

> 归档/OCR 不依赖 Ollama；仅**脱敏的 NER 增强**与**智能问答**需要本机 Ollama。未装时归档照常工作。
